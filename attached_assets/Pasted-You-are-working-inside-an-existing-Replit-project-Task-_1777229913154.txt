Database schema:
Create SQL migration files for:

1. profiles
Fields:
- id uuid primary key references auth.users(id)
- full_name text
- email text unique
- role text check role in ('client','freelancer')
- avatar_url text
- bio text
- skills jsonb default '[]'
- rating numeric default 0
- created_at timestamptz default now()
- updated_at timestamptz default now()

2. services
Fields:
- id uuid primary key
- freelancer_id uuid references profiles(id)
- title_ar text
- title_en text
- description_ar text
- description_en text
- category text
- slug text unique
- status text check status in ('draft','published')
- basic_price numeric
- standard_price numeric
- premium_price numeric
- basic_description text
- standard_description text
- premium_description text
- images text[]
- deleted_at timestamptz
- created_at timestamptz default now()
- updated_at timestamptz default now()

Rules:
- freelancer manages own services
- clients only read published services
- draft services visible only to owner
- deleted_at means soft delete

3. orders
Fields:
- id uuid primary key
- client_id uuid references profiles(id)
- freelancer_id uuid references profiles(id)
- service_id uuid references services(id)
- package_type text check package_type in ('basic','standard','premium','custom')
- total_price numeric check total_price > 0
- platform_fee numeric
- freelancer_earnings numeric
- status text check status in ('pending','active','delivered','completed','cancelled')
- requirements text
- created_at timestamptz default now()
- updated_at timestamptz default now()

Rules:
- client cannot order own service
- client and freelancer can read shared orders
- freelancer can update order status
- commission is calculated in database only

Commission logic:
Create SQL function and BEFORE INSERT trigger:
- platform_fee = ROUND(total_price * 0.15, 2)
- freelancer_earnings = total_price - platform_fee

Do not calculate commission in frontend.

4. wallet_transactions
Fields:
- id uuid primary key
- freelancer_id uuid references profiles(id)
- order_id uuid references orders(id)
- type text check type in ('earning','refund','adjustment')
- amount numeric
- status text check status in ('pending','available','cancelled')
- description text
- created_at timestamptz default now()

Rule:
- wallet balance is computed dynamically from wallet_transactions
- do not add payout system

5. quote_requests
Fields:
- id uuid primary key
- client_id uuid references profiles(id)
- freelancer_id uuid references profiles(id)
- service_id uuid references services(id)
- title text
- description text
- budget numeric
- proposed_price numeric
- status text check status in ('pending','responded','accepted','rejected','converted')
- created_at timestamptz default now()
- updated_at timestamptz default now()

Rules:
- client submits quote
- freelancer responds
- accepted quote can convert to order
- order conversion uses same commission logic

6. conversations
Fields:
- id uuid primary key
- order_id uuid references orders(id)
- quote_request_id uuid references quote_requests(id)
- client_id uuid references profiles(id)
- freelancer_id uuid references profiles(id)
- created_at timestamptz default now()

Rules:
- conversation created when order or quote exists
- only participants can read

7. messages
Fields:
- id uuid primary key
- conversation_id uuid references conversations(id)
- sender_id uuid references profiles(id)
- content text
- type text check type in ('text','file')
- attachment_url text
- is_read boolean default false
- created_at timestamptz default now()

Rules:
- realtime messaging
- only participants can send/read
- sender must be conversation participant

8. notifications
Fields:
- id uuid primary key
- user_id uuid references profiles(id)
- type text

- is_read boolean default false
